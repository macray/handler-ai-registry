# Marketer

An agent that does your product's marketing with
[Marketing Skills](https://github.com/coreyhaines31/marketingskills) by **Corey Haines**
(MIT). The skills are his work, unchanged; this package adds only the agent and an index that
lets it carry the 53 skills as one.

It works in your project's folder: positioning, page copy, conversion (CRO), SEO, ads, email,
launches, pricing, growth. It starts by writing `.agents/product-marketing.md` with you, the
product's audience, positioning and voice, which every skill reads.

## What it brings

- **One skill, `marketing-skills`**, added to Library → Skills: an index of Corey Haines' skills
  and the skills themselves. It holds his license (`LICENSE`) and where it comes from
  (`ORIGIN.md`: the upstream commit, what was left out).
- **No network beyond Handler's default.** To audit a live page or study a competitor, allow
  their hosts in the agent's settings.

With the **Web designer** in the same project, the two work as a pair: the Marketer writes
what the page says, the Web designer how it looks.

Problems with the skills themselves: report them
[upstream](https://github.com/coreyhaines31/marketingskills/issues).
