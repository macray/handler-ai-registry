# Web designer

An agent that designs and builds your product's web pages and app screens with
[taste-skill](https://github.com/Leonxlnx/taste-skill) by **Leonxlnx** (MIT). The skill is their
work, unchanged; this package adds only the agent, and the `taste` tool that runs the skill.

It works in your project's folder, in its own stack: it picks an art direction made for your
product rather than the average landing page, builds it, then checks it in a real browser and
looks at the screenshots until it holds up.

**It needs the `taste` tool**, installed with it when you set it up: it brings the skill, the
browser it checks pages in, and the sites it may find pictures and fonts on.

With the **Marketer** in the same project, the two work as a pair: the Marketer writes what the
page says (`.agents/product-marketing.md` and the copy), the Web designer how it looks.

With the **Interface designer** (Impeccable) in the same project: new pages and redesigns of a
whole page are the Web designer's, improving what already exists is the Interface designer's.
